# ZXW_Project — 基于准直孔与康普顿散射的智能伽马成像算法研究

> **项目来源**：四川大学大学生创新训练计划项目（指导教师：韩纪锋 研究员，四川大学原子核科学技术研究所 / 720所）  
> **远端仓库**：`https://github.com/sanshibro/ZXW_Project.git`

---

## 1. 课题原始命题说明

> **命题说明**：  
> 基于像素化阵列探测器，开展基于准直孔和康普顿散射的智能伽马成像算法研究。通过蒙特卡罗程序构建成像系统，模拟伽马射线的输运以及与探测器的相互作用过程。设置不同源位置、形状，生成多工况标注数据集，结合实际探测器噪声、能量分辨率、位置分辨等进行修正，贴近真实探测场景。  
> 基于数据集设计轻量化 AI 重建网络，对光子作用事例进行甄别、能量与位置信息解析，融合准直投影信息和康普顿散射角信息联合重建，替代传统迭代算法。形成完整算法代码、仿真数据集与性能评估报告，为像素化阵列探测器快速伽马成像提供算法支撑。
>
> **组队要求**：包含核工程与核技术专业的同学，熟悉核探测器，具有编程能力。

## 2. 仓库多分支管理规范（三阶段独立分支）

为保证项目调研分析、申报书撰写与初版 Demo 开发全流程可追溯、互不干扰，本仓库采用**主干索引 + 三大专题分支**架构：

| 分支名称 | 阶段定位 | 核心内容与交付物 | 当前状态 |
| :--- | :--- | :--- | :--- |
| `main` | 仓库总览与导航 | 项目总体说明、分支结构规范、阶段里程碑索引 | 已初始化 |
| `analysis` | **第一阶段：深度调研与解读** | 课题白话与物理深度拆解、导师团队背景调研、50–100篇核心文献精读与分类综述、传统算法对比、申报书与初版 Demo 实施路线图、调研过程记录 | **已完成并推送** |
| `proposal` | **第二阶段：大创申报书撰写** | 四川大学大创项目立项申请书各章节草稿、技术路线图、创新点凝练、经费预算与进度规划 | 已完成并推送 |
| `demo` | **第三阶段：初版 Demo 开发** | 物理与蒙特卡罗仿真数据管线、探测器效应修正模块、事例甄别与轻量化双模融合 AI 重建网络、传统迭代基线（SBP/LM-MLEM）对比及可视化界面 | 已完成并推送 |
